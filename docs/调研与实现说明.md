## 当前实现 · 0.2.1

2026-10-13 根据用户要求扩展为通用网页文字翻译，删除图片识别。手动翻译由用户点击或快捷键触发，通过 activeTab 和 scripting 注入；自动翻译需要逐网站授权，后台登记持久内容脚本。旧 abceed 自动设置仅迁移该网站，不扩展为默认全网读取权限。

扫描文本节点，聚合段落及控件文字，遵循 CSS 空白折叠与显式换行规则。扫描开放 Shadow DOM 并观察动态更新。原文节点不替换；译文作为独立 Shadow DOM 宿主追加，默认悬浮面板则保持原页面 DOM 和布局。登录表单、输入框、代码、媒体与扩展自身界面排除。

追加模式可调整 Flex 换行、最小高度和截断样式。每项调整有引用计数，关闭恢复扩展修改，保留网页在期间写入的样式。异步请求通过 generation 和记录身份核对，避免切题后插入旧译文。翻译全局并发最多 3 个，缓存最多 500 条。

源语言支持服务端自动检测及 16 种手动选择；目标语言提供相同 16 种常用语言。设置、请求及缓存键包含源语言和目标语言。目标为中文时避免重复翻译已有中文段落；纯汉字日文可结合页面 lang 提示或手选日文。

界面语言仅在设置页提供，默认跟随 Chrome 提供的系统界面语言，可覆盖为简体中文、英文或日文；不匹配语言回退英文。界面语言独立保存，切换只重绘扩展界面，不改变译文及翻译请求。

首次授权时 Chrome 可能关闭 popup。后台先在 storage.session 保存十分钟有效的授权意图，监听 permissions.onAdded 并检查实际权限，提交网站设置和脚本规则；取消和过期意图清除。后台重新启动也能继续处理。停用自动翻译后撤销对应注入规则。

Google 网页接口无需密钥，但不承诺可用性或机器翻译准确度。自定义兼容接口需要 HTTPS，允许本机 HTTP；密钥仅本机存储。网页内容作为待翻译文字，不执行其中的指令。

Chrome 原生整页翻译会替换原文，可能与双语扩展叠加。实测站点使用原文视图，并按网站停用原生自动翻译，不修改全局语言设置。

相关官方 API 文档：[activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)、[scripting](https://developer.chrome.com/docs/extensions/reference/api/scripting)、[permissions](https://developer.chrome.com/docs/extensions/reference/api/permissions)。
