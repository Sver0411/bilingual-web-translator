# 双语网页翻译器

| 版本 | 平台 | 许可证 | 翻译语言 |
| :--- | :--- | :--- | :--- |
| 0.2.1 | Chrome 116+ · Manifest V3 | [MIT](LICENSE) | 自动检测源语言 · 16 种目标语言 |

[English](README.md) · **简体中文**

Chrome 通用网页双语翻译扩展，在浏览器中显示为「双语伴读」。保留原文，支持动态页面、按钮、链接和开放的 Shadow DOM。图片识别功能已移除；图片、Canvas、输入框和登录表单保持原样。

## 使用

打开普通 HTTP / HTTPS 网页，点击扩展图标，再点「翻译当前页」。按 Alt+A 也可开关。

- 源语言：默认自动检测，由翻译服务识别；也可手动选择 16 种常用语言。
- 目标语言：简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、意大利语、俄语、阿拉伯语、印地语、泰语、越南语、印度尼西亚语。
- 显示方式：默认悬浮对照，保持原页面布局；可选原文下方追加译文，必要时增加段落或控件高度。关闭时移除译文并恢复扩展调整的样式。
- 自动翻译：勾选「在此网站自动翻译」，允许 Chrome 对该网站的访问请求。之后访问该网站会自动开启；取消勾选即可停用。
- 界面语言：只在「设置与翻译服务」页选择。默认「跟随系统」，根据 Chrome 提供的界面语言匹配中文、英文或日文；其他语言回退为英文。可手动选择简体中文、English 或日本語。选择后点「保存设置」。界面语言与源语言、目标语言分别保存，切换界面不会重新翻译页面。

悬浮面板标题栏可拖动、收起。点击译文定位对应原文，悬停原文可查看译文。滚动、展开内容和页面更新后自动翻译新文字。

## 安装

下载 [bilingual-web-translator.zip](bilingual-web-translator.zip)，或克隆本仓库后使用 `extension` 目录：

1. 解压安装包，打开 Chrome 的 `chrome://extensions`，启用开发者模式。
2. 点击「加载未打包的扩展程序」，选择包含 `manifest.json` 的解压文件夹，或本项目的 `extension` 目录。
3. 刷新要翻译的网页，点击扩展图标。

Chrome 内部页面、扩展商店、内置 PDF 阅读器不允许此类脚本。闭合 Shadow DOM 和未授权跨域嵌入页面不保证支持；图片或 Canvas 中的文字不翻译。无需上传图片。

## 翻译服务与数据

默认 Google 网页翻译接口无需填写密钥，需要能访问 `translate.googleapis.com`。该接口没有稳定性保证，机器翻译可能存在措辞错误；遇到限流或网络错误可重试，或在设置配置自己的 `/chat/completions` 兼容服务。

开启后，屏幕附近的可见文字发送给所选翻译服务。关闭后停止新请求；已发送的请求可能仍在完成。扩展不读取 Cookie、密码、输入框或登录表单。译文最多缓存 500 条，仅存于内存。自定义 API 密钥仅保存在本机扩展设置，不同步；保存时只申请该服务域名的权限。

通用网站手动翻译使用 `activeTab` 临时权限。自动翻译只为用户授权的网站登记脚本，未默认申请全网永久读取权限。保留原来 abceed 的注入范围以兼容旧设置。自动授权意图由后台保存，权限弹窗关闭快捷界面后仍能完成设置。

## 开发与验证

```sh
npm install
npm run check
npm test
npm run serve
```

本地测试页：`http://127.0.0.1:4173/`。使用自编英日题目和同一份 DOM 引擎；不包含真实 abceed 题库。

24 项自动测试覆盖原文节点及点击事件保留、样式恢复、动态内容和迟到响应、非 abceed 网站与开放 Shadow DOM、多语言传参、界面语言独立性及首次权限授权的持久化。验证记录见 [docs/验证记录.md](docs/验证记录.md)。

核心文件：`common.js`（设置与文字过滤）、`i18n.js`（界面本地化）、`engine.js`（文本提取）、`content.js`（双语显示）、`sites.js` / `auto-sites.js`（网站授权与自动注入）、`background.js` / `providers.js`（翻译调度与服务适配）。

这是独立实现的双语扩展，未复制沉浸式翻译的代码、图标或品牌资源，也未声称具备原产品全部功能。图片识别功能不包含在此仓库或安装包中。
